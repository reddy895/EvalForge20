# Standard Benchmark Suites

EvalForge20 packages deterministic test suites:
- **Coding Basics**: Syntax validation, algorithmic problem solving (HumanEval subset).
- **Mathematical Reasoning**: Word problems, multi-step arithmetic (GSM8K subset).
- **Factual QA**: Open-domain knowledge retrieval (MMLU subset).
- **Tool Calling**: Structured argument extraction and action selection.
